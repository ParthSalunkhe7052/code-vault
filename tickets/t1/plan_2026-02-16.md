# CLI Refactor: Decouple Compiler Logic Implementation Plan

## Overview
Refactor the monolithic `cli/compiler_logic.py` into a modular, class-based architecture. This allows for language-specific optimizations (Python Turbo Mode, Node.js Bootstrap) without cluttering the main build flow. We will also switch to `asyncio` for all subprocess management to improve UI responsiveness on Windows.

## Current State Analysis
- `cli/compiler_logic.py`: Contains all logic for both Python and Node.js.
- `run_compiler` (L439): Main entry point for builds.
- `run_nuitka` (L862) and `run_pkg` (L580): Procedural implementations of builds.
- Process management uses blocking `subprocess.Popen` and custom threads (L33).

## Implementation Approach
1. Create a directory `cli/compilers/` to house the new modules.
2. Define a `BaseCompiler` in `cli/compilers/base.py` with abstract methods for `pre_flight`, `inject_wrapper`, and `compile`.
3. Implement `PythonCompiler` and `NodeJSCompiler` subclasses.
4. Replace the procedural calls in `cli/compiler_logic.py` with an orchestrated call to these classes.

## Phase 1: Modular Scaffold & Base Class
### Overview
Establish the new directory structure and the base interface.

### Changes Required:
#### 1. `cli/compilers/base.py` (New File)
**Changes**: Define the abstract interface for all compilers.
```python
from abc import ABC, abstractmethod
from pathlib import Path
from typing import Dict, Any, Optional, Tuple

class BaseCompiler(ABC):
    def __init__(self, project_dir: Path, config: Dict[str, Any]):
        self.project_dir = project_dir
        self.config = config

    @abstractmethod
    async def pre_flight(self) -> bool:
        """Check for tools and environment readiness."""
        pass

    @abstractmethod
    async def inject_wrapper(self) -> bool:
        """Inject license protection."""
        pass

    @abstractmethod
    async def compile(self) -> Tuple[bool, Optional[Path]]:
        """Execute the actual compilation/bundling."""
        pass
```
