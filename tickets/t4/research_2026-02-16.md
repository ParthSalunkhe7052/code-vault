# Research: CLI - Environment Doctor & Pre-flight Checks

**Date**: 2026-02-16

## 1. Executive Summary
The CLI already has basic diagnostic commands (`system status` and `system check` in `cli/codevault_cli/commands/system.py`), but they are not integrated into the build process as pre-flight checks. They also miss critical build-time dependencies like a C++ compiler (GCC/MSVC) which Nuitka requires.

## 2. Technical Context
- **Existing Commands**: 
    - `system status` (L40): Shows a table of dependencies (Nuitka, Node.js, Python, Rich).
    - `system check` (L127): Shows a diagnostic tree of Python and core packages.
- **Dependency Checks**:
    - Nuitka: Calls `sys.executable -m nuitka --version` (L79).
    - Node.js: Calls `node --version` (L97).
- **Architecture**: The commands use `rich` for pretty output, which is good.

## 3. Findings & Analysis
- **Missing Checks**: 
    - **C++ Compiler**: Nuitka requires a C++ compiler on Windows. The current check doesn't verify if one is installed or configured in Nuitka.
    - **Pkg**: The Node.js check only checks for `node`, not `@yao-pkg/pkg` or `npx` availability.
    - **Permissions**: Doesn't check if it has write access to the output directory or desktop.
- **Integration Gap**: The `project build` command (not yet analyzed in detail) likely doesn't call these checks before starting. They are manual commands only.
- **Error Messages**: The current error messages are generic ("Not installed", "Not working"). They should provide installation links or specific remediation steps.

## 4. Technical Constraints
- **Nuitka Compiler Detection**: Finding which compiler Nuitka is using (or if it's missing one) requires parsing `nuitka --version` more carefully or checking Nuitka's internal config.
- **Windows-Specific**: C++ compiler issues are most common on Windows (missing MinGW or MSVC).

## 5. Architecture Documentation
The logic in `cli/codevault_cli/commands/system.py` should be extracted into a reusable `cli/codevault_cli/utils/health.py` module so it can be called by both the `system` commands AND the new `BaseCompiler.pre_flight()` methods.
