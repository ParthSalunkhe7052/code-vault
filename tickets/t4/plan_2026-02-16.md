# CLI: Environment Doctor & Pre-flight Checks Implementation Plan

## Overview
Implement a reusable "Doctor" utility that checks for all required build tools (Python, Nuitka, Node.js, Pkg, C++ Compiler). This utility will be used by the `system` commands and integrated into the build process as a mandatory pre-flight check.

## Current State Analysis
- `cli/codevault_cli/commands/system.py`: Contains redundant check logic.
- `PythonCompiler.pre_flight()` and `NodeJSCompiler.pre_flight()`: Currently have stub/minimal logic.
- Missing checks for C++ compilers and specific node tools.

## Implementation Approach
1. Create `cli/codevault_cli/utils/health.py` containing the check logic.
2. Refactor `system.py` to use these utilities.
3. Update the compiler classes to call the relevant health checks in their `pre_flight` methods.
4. Implement specific check for C++ compiler by parsing `nuitka --version`.
