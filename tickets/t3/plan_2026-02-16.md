# Python: Implement Turbo Mode Optimizations Implementation Plan

## Overview
Implement the "Turbo Mode" optimizations in the CLI's Python compiler. This will reduce binary size and build time by aggressively excluding unused standard library modules, mirroring the server-side compiler's behavior.

## Current State Analysis
- `cli/compilers/python.py`: Basic async implementation without advanced blacklisting.
- `server/compilers/python_compiler.py`: Contains `blacklist_modules` (L235) and `turbo_exclusions` (L275).

## Implementation Approach
1. Define the module blacklists in `cli/compilers/python.py`.
2. Update the `compile()` method to apply these exclusions using `--nofollow-import-to`.
3. Add a `turbo_mode` flag to the build configuration.

## Phase 1: Python Compiler Turbo Logic
### Overview
Integrate the blacklists into the `PythonCompiler` class.

### Changes Required:
#### 1. `cli/compilers/python.py`
**Changes**: Add the module lists and update the `compile` command construction.
```python
PYTHON_BLACKLIST = ["test", "unittest", "pytest", ...]
PYTHON_TURBO_EXCLUSIONS = ["encodings.cp1006", ...]

class PythonCompiler(BaseCompiler):
    async def compile(self):
        # ...
        for module in PYTHON_BLACKLIST:
            cmd.append(f"--nofollow-import-to={module}")
        if self.config.get("turbo_mode", True):
            for module in PYTHON_TURBO_EXCLUSIONS:
                cmd.append(f"--nofollow-import-to={module}")
        # ...
```
