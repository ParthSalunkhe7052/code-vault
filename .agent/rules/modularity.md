# Modularity Rules

## 300-Line Limit
No single file should exceed 300 lines of code.

## Auto-Extraction
If a function exceeds 40 lines, create a plan to extract it into a separate utility file.

## Specialized Workflow
Whenever I start a task, verify if we need to call the refactor.md agent to split existing files before adding new logic.

## Review Policy
Every 'Implementation Plan' artifact must explicitly list which new files will be created to keep existing ones small.
